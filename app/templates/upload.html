🛡️ Ingestion Protocols

  • 1. Non-Destructive Acquisition: Files are read-only streamed and preserved in a secured vault directory without modification.
  • 2. Dual Hash Generation: Both MD5 (128-bit) and SHA-256 (256-bit) are computed immediately to establish bitstream baseline.
  • 3. Magic Byte Analysis: File headers are evaluated against known file signatures to identify spoofed extensions.
  • 4. Deep Metadata Triage: EXIF, GPS tags, document catalog properties, or character statistics are parsed.

⚖️ Evidentiary Standard Notice

Intake establishes an internal baseline. A matching hash confirms that the evidence has not mutated while in custody. It does not certify the historical validity of the file prior to seizure.
